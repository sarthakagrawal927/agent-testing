# Design

## Direction

Field Manual: a quiet, single-column technical guide with warm paper surfaces,
editorial headings, restrained rust actions, and monospace commands. The page
reads in the same order an agent should act: clone, prove, adapt, compare.

## System

- Typography: system sans for instructions, Georgia for the title, system
  monospace for commands and machine-oriented labels.
- Color: warm neutral surfaces, near-black text, restrained rust links and
  actions, green only for verified outcomes. No decorative accent stripe.
- Layout: one centered reading column with a narrow route rail on wider
  screens; no application shell, cards grid, or hidden navigation.
- Interaction: ordinary links with visible focus; no client JavaScript or
  motion required.

The owner chose the existing field-guide system and explicitly rejected added
visual concepts as over-engineered. The site uses no UI runtime dependency.
