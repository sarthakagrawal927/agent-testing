# Design

## Direction

Field Manual: a quiet, single-column technical guide with warm paper surfaces,
one orange route marker, editorial headings, and monospace commands. The page
reads in the same order an agent should act: clone, prove, adapt, compare.

## System

- Typography: system sans for instructions, Georgia for the title, system
  monospace for commands and machine-oriented labels.
- Color: warm neutral surfaces, near-black text, orange actions and route
  markers, green only for verified outcomes.
- Layout: one centered reading column with a narrow route rail on wider
  screens; no application shell, cards grid, or hidden navigation.
- Interaction: ordinary links with visible focus; no client JavaScript or
  motion required.

The owner delegated the choice by saying “anything simple would do.” The page
adapts the narrow editorial hierarchy of Preline's public Cover Page example
without adding Tailwind, Preline, or any runtime dependency:
https://preline.co/examples/html/cover-page.html
